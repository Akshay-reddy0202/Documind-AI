# DocuMind AI

DocuMind AI is a GenAI-powered document assistant that uses
Retrieval-Augmented Generation (RAG) and AI agent tools to
answer questions about uploaded documents.

## Project Structure

- `frontend/` - React and TypeScript application
- `backend/` - Node.js, Express, and TypeScript API

## Planned Features

- Document upload and management
- Document summarization
- Evidence-based question answering
- Semantic search using embeddings
- Source citations
- Tool-using AI agent
- Conversation history

## Technology Stack

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- pgvector
- LLM API
